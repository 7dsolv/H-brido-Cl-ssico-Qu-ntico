# Como contribuir

Forks e pull requests são bem-vindos.

1. Abra uma issue descrevendo a mudança.
2. Crie uma branch no seu fork.
3. Adicione testes para novos estados, portas ou cálculos.
4. Execute `python -m unittest discover -s tests -v`.
5. Abra o pull request explicando hipóteses, limites e resultados.

Não descreva uma simulação clássica como hardware quântico real. Novas fórmulas devem definir seus símbolos e usar blocos ` ```math ` sem indentação.
